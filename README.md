# Семинар — обратная связь / Кері байланыс

Анонимный опрос на русском и казахском языках. Четыре вопроса, оценка звёздами, обязательные вопросы 1–3, необязательные пожелания. Сервер хранит ответы в D1. Страница `/#admin` защищена паролем на сервере, показывает сводку и выгружает CSV. Пароль не включён в исходники.

## Текущий статус
Подготовлены интерфейс, сервер и публикация GitHub Pages. Исходники загружены в GitHub: Akizhanov/seminar-feedback. Сервер Sites в текущем аккаунте ограничен доступом владельца: использовать его для открытого опроса нельзя. Для участников нужен публичный сервер, например Cloudflare Worker с D1. Не распространяйте текущую ссылку до настройки публичного сервера и проверки сохранения с другого устройства.

## Публичный сервер Cloudflare
1. В аккаунте Cloudflare создайте D1: `npx wrangler d1 create seminar-feedback`.
2. В `wrangler.jsonc` замените `REPLACE_WITH_D1_DATABASE_ID` полученным ID.
3. Выполните `npx wrangler d1 migrations apply seminar-feedback --remote`.
4. Создайте надёжный пароль: `npx wrangler secret put ADMIN_PASSWORD`. Не добавляйте его в репозиторий.
5. Замените константу `API` в `index.html`, `dist/index.html` и `github-pages/index.html` URL публичного Worker.
6. Выполните `node build.mjs`, затем `npx wrangler deploy`.
7. Проверьте опрос и `/#admin` с реальным сервером. Проверочный ответ попадёт в сводку.

## GitHub Pages
Откройте Settings → Pages → Deploy from a branch → main → /(root) → Save. index.html находится в корне. Для страницы организатора добавьте `/#admin` к ссылке.

Публикация только `github-pages/index.html` даёт интерфейс. Для сохранения ответов обязательно нужен работающий публичный сервер из предыдущего раздела.

## Проверки
Проверены синтаксис JS, валидация входящих ответов, отказ без пароля, сохранение, чтение и защита от дублирования при повторной отправке одного запроса. Полная проверка браузера и реального D1 после публичного развёртывания ещё требуется.
